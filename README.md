# Project 03: Fission process of unstable isotope Uranium 235.


## Overview

This project involved developing a Python simulation of an unstable isotope undergoing radioactive decay. The simulation models the decay process and tracks the resulting daughter particles, allowing their behaviour and statistical properties to be observed and analyzed.

## Project Work

- Developed a Python simulation to model the probabilistic decay of an unstable isotope
- Implemented a method for tracking daughter particles produced through the decay process
- Collected and analyzed simulation data to observe patterns in radioactive decay
- Compared simulated behaviour with theoretical expectations for radioactive decay

## Skills Demonstrated

- Python programming
- Computational modelling and simulation
- Data collection and analysis
- Statistical analysis
- Scientific visualization
